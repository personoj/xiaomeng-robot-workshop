## 六轴运动与定长管线（当前版本）

模型预览底部“播放运动 / 暂停运动”播放24秒六轴往返循环，五次多项式平滑插值使换向速度、加速度连续。手动关节同样通过约束检查；发生碰撞、过弯或线长不足时，保持上一合法姿态并展示原因。新“基座接头”近景用于查看连接安装面。

- 主波纹管 1.600 m、红色供给管 1.350 m、送丝线 1.120 m，为本模型明确选定的标称长度，不是厂家实测值。每帧解算固定总长和接头切向，允许改变弯曲形状，禁止用伸缩补偿姿态。波纹环按固定弧长位置排列，几何缓冲区原地更新。
- 管线采用带半径的胶囊分段对原厂臂体、线盘转子、送丝机构及主要机身实体做BVH三角形检查；检查管线互碰/自碰、线盘与机身、非相邻连杆及机箱碰撞。相连袖口和正常出丝接触具有局部接触范围。每次位姿变化按不超过0.5°插分检查。
- 悬空的肩部接头已经移除。主线束通过有四颗螺栓的法兰接入基座实体侧面，密封垫适配原厂网格约1.2mm台阶；八个安装面射线检验确认实际承托面位于垫片压缩范围内。不是只将软管端点绑定到另一个悬空零件。
- 线盘文字重新居中并贴近表面；独立检查全部文字顶点在转盘圆面内，避免铭字伸出盘面悬空。

实现文件：frontend/cable-constraints.js（定长与碰撞约束）、welding-model.js（安装与姿态事务）、welding-motion.js（共享24秒运动轨迹）、model-studio.js（播放/暂停/拒绝反馈）。three-mesh-bvh是新增运行依赖。

执行 `node scripts/check-welding-motion.mjs` 后，motion-validation.json记录整段721帧：4096段独立积分测得最大线长误差0.036mm，端点误差在浮点精度范围内；三个故意越界姿态被阻止，原合法姿态保持不变；文字范围与接头安装面检查通过。再执行原GLB导出及Vite构建，均通过。

这是定长、弯曲和几何碰撞约束的准静态预览。未模拟材料弹性、惯性、接触摩擦与真实控制器；离散轨迹/碰撞近似不能代替实体机构的全范围安全认证。

浏览器验收：播放与暂停正常，六轴姿态随时间改变，实时误差约0.035mm；手动将J1拖到150°时提示“主波纹管接近线盘转动部分”，实际姿态保持原值，恢复后继续播放。基座接头近景确认法兰贴合机身，控制台无错误。截图：.local/welding-motion-base-port.png、welding-motion-blocked.png、welding-motion-running.png。


## 管排现场参考重建与轨迹熔敷（当前）

用户已确认机器人模型完成。本轮只重建管排，按讨论047–049纠正为相邻钢管直接通过一段段焊肉相连。原宽间距与扁钢两侧双线方案已移除。当前8根空心管平行、端口齐平，长2400mm、外径76mm、壁厚4mm、中心距76.8mm、净间隙0.8mm。尺寸均为示意选值。端面真实环形开口和外倒角；程序化钢材颜色、微法线与金属/粗糙度映射可导出，支承梁接触管底。

每对相邻钢管一条定位缝，共7条。焊后外观对照包含98个短焊段，单段约32mm，熔敷截面按两侧圆管表面生成并跨接两管，有连续焊肉和细密波纹，不是两根分开的银色线。默认无焊痕；查看器提供焊前/焊后、管口/焊缝细节。颜色扫描线、TCP箭头属于后续演示叠层，没有烘入工件。

实现独立于机器人模型，位于 frontend/tube-panel-model.js。静态比较用 setPanelWeldPreview(panel, boolean)。真实演示将调用 appendPanelWeldContact(panel, {seamId, position, arcOn})：position须来自接受后的焊枪实际接触轨迹，在管排局部坐标下、米单位；不能传规划终点或用计时器百分比冒充。当前对象只有直管缝，接口使用沿X轴接缝投影的实际前进距离；离缝超过1.5mm或离接触高度超过2mm就中断沉积。不是通用自由曲面熔池求解器。

从第一个实际接触点开始，后续移动增添截面和三角形，长度不预设；旧顶点保持不动，表现为枪尖后方连续留下焊肉。停止不加长、停弧/抬枪结束当前段、再起弧形成新段；超过25mm的采样跳跃不补画，转向作为新熔敷段。clearPanelWeldTrace复位。轨迹接口已完成，机械臂/语音/扫描尚未接入这套焊接执行逻辑，下一阶段再讨论控制模板。

验证：node scripts/check-pipe-panel.mjs。检查8个通孔和实测几何壁厚、196次双侧管壁接合射线（98焊段×2），以及实际接触点推进、已沉积顶点固定、停枪、停弧、离缝/抬枪、跳跃及清空。结果输出pipe-panel-validation.json。导出重载包括tube-panel.glb（未焊，约3.94MB）和tube-panel-welded.glb（静态焊后，约11.59MB），均保留3张纹理。npm run build后8090无需重启。
