# 同场景焊接执行（2026-10-11）

## 用户流程

说“焊接管排1的第二条缝”。千问从场内管排×焊缝的有限候选选择参数，程序核对编号。焊缝从上到下1到7；多个管排未指明、只说“一条缝”或编号不存在时先澄清/拒绝。语音工具为 `weld_workshop_seam`。

任务先预检整个动作，随后底盘沿管排方向行走、机械臂保持枪姿并修正枪尖位置，逐点沿缝焊接，最后停弧退枪。采用已接受厂家网格模型和现有定长管线，不切换场景、不重建抓取台、不重排其他对象。

## 执行与数据

- `scripts/plan-workshop-weld.mjs` 用同一可动模型执行IK、实际枪尖FK、定长管线/接头锚定、自碰撞和外部碰撞预检。外部包括全部管排、支架、底脚、后墙和抓取工作台。
- `workshop_welding.py` 在服务端执行预检后的姿态帧。焊肉接触点由模型实际 `weld_tcp` 转为管排局部坐标后记录，不按计时器或目标线长度伪造。
- 模型和焊枪实际姿态进入场景状态；`weld_runs` 持久化已执行接触点，刷新恢复同一焊肉。前端批量恢复时合并法线/边界更新，避免长缝逐点重建卡顿。
- 暂停冻结底盘、关节、采样与焊肉长度；停止保留现场和已焊部分。光效只在执行中的有效起弧帧显示，快照失联时熄弧，残烟自然消散。
- 模型焊接为受约束运动学仿真，没有将实体设备、焊接工艺热力学或底盘接触动力学冒充为已验证能力。抓取台仍使用MuJoCo。

- 第三条缝完整完成约2.3497m熔敷并停弧退枪。1,402个已预检执行帧，管长最大误差0.03697mm、接头误差约浮点精度、枪尖对缝误差0.00855mm，预检未发现碰撞。
- 第一条缝实际完整执行完成；第七条缝含立柱/底脚的1,688帧预检通过，管长最大误差0.03908mm。每次新任务仍按当时场景重新预检，不能将这几条用例扩称任意摆放均可达。

- 焊缝引用检查、前端版本与未知结果检查、光效生命周期检查和生产构建通过。
- 浏览器已检视完成状态、场景保留、刷新恢复与桌架近景；当前工作坊显示已连接语音服务。此次没有新的ESP32口述/声学验收，API执行测试与该验收区分。

## 同轮外观修正

球状临时焊点撤掉，检视页复用真实管缝与贴合管壁的焊肉，枪丝落在接触处。弧光源受遮挡判断，镜头光芒向外扩散，不再用一张被管面裁断的发光平面。纯正对气嘴时气嘴可遮住光芯，这是实际遮挡。

桌架按MuJoCo台面1.10×0.86m统一中心：围框贴住台面下沿并适当内收，四腿对齐，补水平撑与脚垫。管排底脚移到背侧，让车轮通道留有空间，并加入规划碰撞模型。
