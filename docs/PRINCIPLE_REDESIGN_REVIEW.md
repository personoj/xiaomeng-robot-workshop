## 首次视觉差距记录

本节保留第一次联系人图的审查依据；其中已修正项以“冻结版逐项复核”为准，不应继续作为当前缺陷引用。

### 坐标变换

参考中的悬空点、亮轴、玻璃平面形成明确的纵向张力；当前联系人图主体纵向占比较小，轴箭头短而细，顶部空白较多。参考的亮轴具有明亮芯线、较宽但较淡的辉光及近地反射；当前多为均匀细蓝线，玻璃台更接近平面信息图。

建议优先增加轴长、箭头头部和纵向构图占比，补局部近地反射，压暗非重点背景。不要用整体提亮、增加漂浮粒子来替代局部光感。标签的深底只需足以遮开后方线条，大片黑色标签底会破坏参考的干净感。

### 逆运动学

金属机械臂的主体轮廓比旧图更接近参考，但连杆偏细，关节像平面深色圆盘，底座和地面之间缺少参考中的短反射和接触光。建议适度加厚杆体、增强关节一侧窄亮边与另一侧暗面，不必增加机械零件数量。

`q₂`标签在联系人图中落到肘部较远的下方，`Δq`则悬在左侧空白区，没有明确关联。标签应靠近对应关节弧或局部变化箭头，并避开杆体，而不是用更大的文字补救。

### PointNet++

参考靠前后珠粒大小、明暗与遮挡体现弯管体积；当前候选首段几乎从侧面看等间距点阵，较像两个矩形格点板。第一句称为管道时管口不明显，第二句称“不排成网格”时画面却呈现规则格点。

建议起始镜头就保持可辨的斜角和管口，以确定性小幅扰动生成实际输入点，FPS与邻域查询继续使用同一组点。提高前后珠粒的大小和明暗区别，保留后表面遮挡；不要添加不参与算法的装饰点冒充密度。

### 碰撞与规划

当前圆柱和路径位置关系清楚，但台面比参考更扁，圆柱明暗偏均匀，禁入区的橙边太淡。参考的玻璃台和金属柱通过局部高光、暗侧和落地反射分离层次。

建议适度增加台面纵深，突出金属亮边及暗侧、橙色禁入边界与近地反射。布局上的起点、目标、障碍应保持稳定，不能为了更像参考而改变路径检查结果。

## v1逐帧统计的解释

以下数据来自主agent冻结源码后的 `.local/motion-review/keyframes-v1/audit.json`，30 fps、600×430、共7,225帧。它是旧候选的量化证据，不是修订后统计。

| 主题 | 完全重复帧占比 | 近静止帧占比 |
| --- | ---: | ---: |
| 坐标变换 | 11.02% | 30.92% |
| 逆运动学 | 6.03% | 34.75% |
| PointNet++ | 3.21% | 7.51% |
| 碰撞与路径规划 | 1.11% | 29.31% |

v1没有超过1秒的连续完全冻结区间，但坐标、逆运动学、规划仍有较高的近静止比例。不能仅通过让一个小光点持续移动来宣称教学动画有足够变化；需要结合讲到的概念判断主画面是否给出新的理解线索。反过来，阅读公式需要的短暂稳定也不应机械地删除。

PointNet第4章的最大局部差分为10.9586%，发生在约49.00秒。它不是单帧孤立尖峰：约48.90–49.13秒多帧都在10.7%左右，对应整簇点与玻璃球左移缩小。高频珠粒整体移动本来会形成较大的局部像素差，所以这不能直接计作“硬切帧”；应结合连续轨迹、速度和肉眼回看判断。语义前移后的新版需重新审计，不能沿用这项数值。

v1统计和上述旧问题用于追踪修改，不作为最终通过凭证。当前已取得的检查范围见前面的“客观检查与设备证据”；Canvas检查没有覆盖的DOM公式与任意窄屏布局，不以零问题统计代替实测。
